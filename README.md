# 과제 솔빙 뷰어 (Netlify용)

칩 PDF를 넣으면 문제 · 답지 · 답안 검증 · 해설을 한 화면에 보여 주는 웹앱.
칩마다 **제목 + 비밀번호 4자리**로 등록하면, 어느 기기·브라우저에서든 **등록된 칩 찾기**에서 제목으로 찾고 비밀번호를 넣어 열 수 있음.

## 배포 (GitHub 연결 필수 · 드래그 앤 드롭은 등록/찾기가 안 됨)
1. 이 폴더의 내용물을 GitHub 저장소에 올리기
2. Netlify → Add new project → Import an existing project → GitHub → 저장소 선택
   - Build command: 비워 두기 / Publish directory: `.` → Deploy
3. 끝. **환경변수 없이 바로 동작**해요.

AI(앱 안에서 검증·해설·질문)까지 쓰려면 환경변수 두 개를 넣고 다시 배포:
- `ANTHROPIC_API_KEY` = Claude API 키 (사용량만큼 요금)
- `SESSION_SECRET` = 아무 긴 문자열

## 쓰는 법
- 칩 PDF 넣기 → 바로 열림 → 등록 창에서 제목·비밀번호 4자리 정하기 → 등록
- 다른 기기: 사이트 열기 → 등록된 칩 찾기 → 제목 누르기 → 비밀번호 4자리 → 열림
- 한 번 연 기기는 30일 동안 비밀번호 다시 안 물어봄
- 비밀번호 5번 틀리면 그 칩은 15분 잠김
- 같은 제목으로 다시 등록하면 그 칩의 비밀번호를 맞게 넣었을 때만 새 내용으로 바뀜

## 참고
- 찾기 목록에는 제목만 보이고, 내용은 비밀번호를 넣어야 열려요.
- 저장된 칩: Netlify 대시보드 → Blobs → `hwviewer`
